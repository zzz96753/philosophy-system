# 02 · 预训练 · 微调 · 对齐

> LLM 从「会预测下一个词」到「听话、有用、无害」的全过程。RLHF / DPO 是面试重灾区。

---

## 一、训练三阶段全景

```
预训练 (Pretrain)  →  监督微调 (SFT)  →  偏好对齐 (RLHF / DPO)
  海量无标注文本        高质量指令数据        人类偏好数据
  学语言与世界知识      学会按指令回答        学会符合人类偏好
```

### 1. 预训练（Pretraining）
- 目标：自回归语言建模，最大化 $\prod P(x_t \mid x_{<t})$
- 数据：TB 级网页/代码/书籍，清洗去重是关键
- 产物：base model，有知识但不一定「听话」

### 2. 监督微调 SFT（Supervised Fine-Tuning）
- 用「指令 → 理想回答」对，做有监督的下一词预测
- 让模型学会指令跟随的格式与风格
- 数据质量 >> 数量（少量高质量优于海量低质）

### 3. 偏好对齐（Alignment）
让模型输出更符合人类偏好（有用、诚实、无害）。两条主流路线：RLHF 和 DPO。

---

## 二、RLHF（基于人类反馈的强化学习）

三个阶段：

1. **SFT**：得到初始策略模型
2. **训练奖励模型 RM**：收集人类对同一 prompt 多个回答的排序，训练一个打分模型 $r_\theta$，让被偏好回答得分更高（Bradley-Terry 损失）
3. **RL 优化（PPO）**：用 RM 当奖励，PPO 更新策略，最大化奖励，同时加 **KL 惩罚** 防止偏离 SFT 模型太远（防止 reward hacking / 语言退化）

目标函数（概念形式）：
$$\max_\pi \ \mathbb{E}[r_\theta(x,y)] - \beta\, \text{KL}(\pi \,\|\, \pi_{\text{SFT}})$$

**为什么要 KL 惩罚？** 防止策略为了刷高 RM 分数而生成胡言乱语（reward model 是不完美的代理）。

---

## 三、DPO（Direct Preference Optimization）

核心思想：**跳过显式奖励模型和 RL，直接用偏好数据优化策略。**

把 RLHF 的最优解析解代回，推导出可以直接在偏好对 $(y_w \text{优于} y_l)$ 上做的分类损失：

$$\mathcal{L}_{DPO} = -\log \sigma\!\left(\beta \log\frac{\pi(y_w|x)}{\pi_{ref}(y_w|x)} - \beta \log\frac{\pi(y_l|x)}{\pi_{ref}(y_l|x)}\right)$$

直觉：提高「被偏好回答」相对参考模型的概率，压低「被拒绝回答」的概率。

### RLHF vs DPO 对比（高频）

| 维度 | RLHF (PPO) | DPO |
|---|---|---|
| 是否需要独立 RM | 需要 | 不需要（隐式） |
| 训练流程 | 复杂（3 阶段、在线采样） | 简单（监督式分类损失） |
| 稳定性 | RL 调参难、易崩 | 更稳、更易复现 |
| 数据 | 排序/打分 | 成对偏好 |
| 表达上限 | 在线探索，潜力高 | 离线，受数据分布限制 |

**一句话本质区别**：RLHF 显式学奖励再用 RL 优化；DPO 用数学等价把这个过程压成一个直接在偏好数据上的监督损失。

## 四、参数高效微调（PEFT）

全量微调成本高，常用 LoRA：

- **LoRA**：冻结原权重 $W$，只学低秩增量 $\Delta W = BA$（$B\in\mathbb{R}^{d\times r}, A\in\mathbb{R}^{r\times k}, r\ll d$）。推理时可合并，几乎零额外延迟。
- **QLoRA**：在 4-bit 量化的基座上做 LoRA，单卡也能微调大模型。
- 为什么有效：微调的「能力增量」本身是低秩的，少量参数即可捕捉。

## 五、面试高频问答

**Q：SFT 和预训练损失函数一样吗？** 都是下一词预测的交叉熵，区别在数据（指令对 vs 海量文本）和通常只对回答部分算 loss。

**Q：没有 RM 的 DPO 真的不需要奖励模型吗？** DPO 把奖励隐式编码进了策略与参考模型的对数比里，等价于有一个奖励模型，只是不用单独训练和在线采样。

**Q：RLHF 里的 reference model 是谁？** 通常是 SFT 模型，KL 项约束策略别跑太远。DPO 里的 $\pi_{ref}$ 同理。

**Q：对齐税（alignment tax）是什么？** 对齐后模型在某些基准能力可能下降，是「更听话」与「更强」之间的取舍。

---

## 六、追问陷阱

- **「PPO 为什么比直接策略梯度稳？」** → clip 限制每步更新幅度，避免策略剧烈变化导致崩溃。
- **「DPO 的 β 控制什么？」** → 对参考模型的偏离程度，β 大则更保守。
- **「LoRA 的 r 怎么选？」** → 任务越复杂/数据越多可适当增大；太大失去效率优势，太小欠拟合。
- **「为什么不直接用更多 SFT 数据，非要 RLHF/DPO？」** → SFT 只能模仿「正确答案」，无法表达「A 比 B 好多少」的相对偏好，也难惩罚坏输出；偏好优化能利用负样本。
