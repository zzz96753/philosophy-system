# 01 · 多模态大模型

> 从「图文对齐」到「视觉对话」。具身智能的感知与语言接口大量基于这些工作。

---

## 一、CLIP：对比学习对齐图文

**目标**：把图像和文本映射到同一语义空间，匹配的图文对相近，不匹配的远离。

- 双塔结构：图像编码器（ViT/ResNet）+ 文本编码器（Transformer）
- **对比损失（InfoNCE）**：一个 batch 内 N 个图文对，构成 N×N 相似度矩阵，对角线为正样本，其余为负样本，做对称的交叉熵
- 训练数据：4 亿网络图文对
- 能力：**zero-shot 分类**（把类别写成 "a photo of a {class}" 和图像比相似度）、检索、作为下游视觉编码器

**为什么强**：自然语言监督 + 海量数据 → 开放词表、强泛化。

---

## 二、ViT：视觉 Transformer

- 把图像切成 patch（如 16×16），每个 patch 线性投影成 token
- 加位置编码 + [CLS] token，喂进标准 Transformer Encoder
- 直觉：把图像当成「patch 序列」，用注意力建模全局关系
- vs CNN：弱归纳偏置（无局部性/平移不变假设），需要更多数据才能超过 CNN，但 scale 上限更高

---

## 三、视觉语言模型（VLM）：让 LLM 看懂图

典型架构（以 LLaVA 为例）：

```
图像 → 视觉编码器(CLIP ViT) → 视觉特征
                                  ↓
                            投影层(MLP/Q-Former)  → 视觉 token
                                  ↓
文本 prompt → 文本 token ──────→ 拼接 → LLM → 文本输出
```

关键设计：**如何把视觉特征接入 LLM 的 token 空间**

- **LLaVA**：用简单 MLP 投影 + 视觉指令微调，简单有效
- **BLIP-2 / Q-Former**：用一组可学习 query 通过交叉注意力「提炼」视觉特征，压缩 token 数、对齐语言空间
- **Flamingo**：用 gated cross-attention 把视觉插进 LLM 各层，擅长少样本

训练通常两阶段：①对齐预训练（冻结 LLM，训投影层）②视觉指令微调（端到端或部分解冻）。

## 四、面试高频问答

**Q：CLIP 的对比学习为什么用大 batch？** 负样本来自同 batch，batch 越大负样本越多、对比信号越强，所以 CLIP 用超大 batch（32K）。

**Q：ViT 相比 CNN 的优劣？** ViT 全局建模强、scale 性好，但数据需求大、缺归纳偏置；小数据下 CNN 往往更优。

**Q：VLM 里视觉 token 太多怎么办？** 高分辨率图产生大量 patch token，挤占上下文。Q-Former、token 压缩/池化、resampler 等用于减少视觉 token 数。

**Q：为什么常冻结视觉编码器？** CLIP 视觉特征已很强，冻结省算力、防过拟合；后期可解冻做端到端精调。

---

## 五、追问陷阱

- **「CLIP 能做检测/分割吗？」** → 原生不能（图像级对齐），需 GLIP/SAM 等区域级方法扩展。
- **「Q-Former 解决什么？」** → 视觉特征与语言空间的「模态鸿沟」+ token 数量过多。
- **「多模态幻觉从哪来？」** → 语言先验过强、视觉对齐不足，模型「凭语言猜」而非「看图说」。
- **「与具身的联系？」** → VLM 是 VLA 的感知-语言底座，VLA = VLM + 动作输出（见下一篇）。
