# 02 · 模仿学习与强化学习

> 具身策略学习的两大支柱。distribution shift 和 PPO 是必问点。

---

## 一、模仿学习（Imitation Learning）

从专家示范中学策略，不需要奖励函数。

### 行为克隆（BC, Behavior Cloning）
- 把「状态 → 专家动作」当成监督学习，最小化预测动作与专家动作的差异
- 简单、稳定、样本高效
- **致命问题：distribution shift（协变量偏移 / compounding error）**

### Distribution Shift 问题（高频！）
训练时模型只见过专家访问过的状态。一旦推理时犯小错，进入专家从未到过的状态，模型不知如何应对，错误**累积发散**（误差随时间步指数增长）。

缓解方法：
- **DAgger（Dataset Aggregation）**：迭代地让学生策略跑、专家对学生访问到的新状态打标，加入数据集重训。让训练分布逼近测试分布。代价：需要在线查询专家。
- **数据增强 / 加噪**：在示范中加扰动，覆盖更多状态
- **Action Chunking（如 ACT）**：一次预测一段动作，减少决策频率和误差累积
- **更强的多模态策略**：Diffusion Policy 等能建模多峰动作分布，避免「平均」掉

### 为什么 BC 会把多模态动作「平均坏」
若专家在某状态有多种合理动作（绕左/绕右），MSE 回归会取平均（直接撞上去）。需要能建模多峰分布的方法（扩散、VAE、离散化）。

## 二、强化学习（Reinforcement Learning）

通过与环境交互、最大化累积奖励学策略。

### 基本概念
- MDP：状态 $s$、动作 $a$、转移 $P(s'|s,a)$、奖励 $r$、折扣 $\gamma$
- 目标：最大化期望回报 $\mathbb{E}[\sum_t \gamma^t r_t]$
- 价值函数 $V(s)$、动作价值 $Q(s,a)$、优势 $A(s,a)=Q-V$

### 主流算法
- **PPO（Proximal Policy Optimization）**：策略梯度 + clip 限制更新幅度，稳、好调，工业界默认。也是 RLHF 用的算法。
- **SAC（Soft Actor-Critic）**：off-policy + 最大熵，样本效率高，适合连续控制（机器人常用）。
- **DDPG/TD3**：确定性策略 + Q 学习，连续动作。
- **离线 RL（Offline RL）**：只用固定数据集学，不交互，适合机器人（真机交互贵）。挑战：分布外动作高估，需 CQL/IQL 等约束。

### On-policy vs Off-policy
- On-policy（PPO）：只能用当前策略采的数据，样本效率低但稳
- Off-policy（SAC/DDPG）：可复用历史数据（replay buffer），样本效率高

## 三、模仿 vs 强化 对比

| | 模仿学习 | 强化学习 |
|---|---|---|
| 是否需奖励 | 否（需示范） | 是（需设计奖励） |
| 样本效率 | 高 | 低（尤其 on-policy） |
| 性能上限 | ≤ 专家 | 可超人 |
| 主要问题 | distribution shift | 奖励设计、探索、稳定性 |
| 真机友好 | 较好 | 难（交互贵、不安全） |

实践常**结合**：BC 预训练 + RL 微调（如先模仿再用 RL 提升），或离线 RL。

## 四、面试高频问答

**Q：为什么机器人领域偏爱模仿学习？** 真机 RL 交互昂贵且危险，奖励难设计；示范数据相对易得，BC 稳定可控。

**Q：PPO 的 clip 起什么作用？** 限制新旧策略概率比在 $[1-\epsilon, 1+\epsilon]$，防止单步更新过大导致策略崩溃，是它稳定的关键。

**Q：稀疏奖励怎么办？** reward shaping、好奇心/内在奖励、HER（事后经验回放）、课程学习、或改用模仿学习提供密集信号。

**Q：离线 RL 难在哪？** 不能交互纠错，模型对数据中没出现的动作会高估价值（外推误差），需保守性约束（CQL 压低 OOD 动作的 Q 值）。

---

## 五、追问陷阱

- **「BC 和监督学习区别？」** → 形式上是监督学习，但因为是序贯决策，存在 distribution shift，这是和普通监督学习的本质差异。
- **「DAgger 的代价？」** → 需要专家在线对新状态打标，成本高、专家不一定随叫随到。
- **「PPO 和 RLHF 的联系？」** → RLHF 第三阶段就是用 PPO，奖励来自训练好的奖励模型。
- **「Action chunking 为什么能缓解误差累积？」** → 降低决策频率、减少高频抖动，并隐式建模时序一致性。
