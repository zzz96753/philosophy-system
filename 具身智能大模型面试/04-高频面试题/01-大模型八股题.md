# 01 · 大模型八股题（带参考答案）

> 先合上答案自己讲一遍，再对照。能讲出「动机」而不只是「定义」才算过。

---

### 注意力与架构

**1. 解释 self-attention，并说明 √d_k 的作用。**
见 `01-大模型基础/01`。要点：Q·K 算相似度，softmax 加权 V；√d_k 控制点积方差，防止 softmax 饱和导致梯度消失。

**2. 多头注意力的意义？**
多个子空间并行关注不同关系，集成效果，计算量与单大头相当。

**3. Pre-LN vs Post-LN？**
Pre-LN 残差路径干净、梯度稳、易 scale，现代 LLM 主流；Post-LN 表达略强但需 warmup、深层不稳。

**4. Encoder-only / Decoder-only / Encoder-Decoder 各适合什么？**
Encoder（BERT）→ 理解类；Decoder（GPT）→ 生成类；Enc-Dec（T5）→ 翻译/摘要等 seq2seq。

**5. 为什么 LLM 主流是 Decoder-only？**
统一用自回归生成、训练简单、scaling 好、few-shot 能力强，工程统一。

### 训练与对齐

**6. 预训练、SFT、RLHF 各自目标？**
预训练学知识；SFT 学指令跟随；RLHF/DPO 对齐人类偏好。

**7. RLHF 三阶段？**
SFT → 训奖励模型（人类排序）→ PPO 优化（带 KL 惩罚）。

**8. RLHF 里 KL 惩罚的作用？**
防止策略为刷奖励而偏离 SFT 太远、产生退化文本（reward hacking）。

**9. DPO 相比 RLHF 的优势？**
无需独立奖励模型和在线 RL，监督式损失，稳定易复现；本质是 RLHF 最优解的解析化。

**10. LoRA 原理及为何有效？**
冻结原权重，学低秩增量 ΔW=BA；微调能力增量本身低秩，少参数即可，省显存、可合并零延迟。

**11. QLoRA 关键？**
在 4-bit 量化基座上做 LoRA，单卡微调大模型。

**12. 灾难性遗忘怎么缓解？**
混入预训练/通用数据、PEFT（只动少量参数）、较小学习率、回放。

### 推理与工程

**13. KV Cache 是什么，代价？**
缓存历史 K/V 避免重算；代价是显存随序列长和 batch 线性增长。

**14. MQA / GQA 解决什么？**
共享 K/V 缩小 KV Cache，缓解长上下文/高并发显存压力，质量损失小。

**15. prefill 和 decode 阶段差异？**
prefill 计算密集可并行；decode 访存密集、逐 token、是延迟瓶颈。

**16. 量化 PTQ vs QAT？**
PTQ 训练后量化、快但可能掉点（GPTQ/AWQ）；QAT 训练中模拟量化、精度好但贵。

**17. 投机解码原理？**
小模型草拟、大模型并行验证接受正确前缀，不改变输出分布而加速。

**18. 数据/张量/流水并行区别？**
DP 切数据；TP 切单层权重（通信频繁，机内）；PP 切层（stage 间通信，有 bubble）。ZeRO 分片优化器状态/梯度/参数省显存。

### 概念辨析

**19. 温度（temperature）和 top-p 作用？**
温度调 logits 平滑度控随机性；top-p 截断累计概率核采样，控多样性与质量。

**20. 幻觉（hallucination）成因与缓解？**
成因：训练目标是流畅性非真实性、知识过期、缺证据。缓解：RAG 检索增强、对齐、引用、降温度。

**21. RAG 是什么，何时用？**
检索相关文档拼进上下文再生成；用于知识更新、减少幻觉、私域知识，无需重训。

**22. Scaling Law 说明了什么？**
模型性能随参数/数据/算力呈幂律提升，指导资源分配（如 Chinchilla：数据要和参数匹配增长）。

**23. MoE（混合专家）原理与优势？**
每 token 只激活部分专家，参数量大但计算量小，性价比高；挑战是负载均衡、训练稳定、通信。

**24. 涌现能力（emergent ability）？**
某些能力在模型规模到一定阈值才突然出现（有争议，部分是评测指标非线性所致）。
