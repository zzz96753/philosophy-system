## 1. Scaled Dot-Product Attention（含 mask）

```python
import torch
import torch.nn.functional as F

def scaled_dot_product_attention(Q, K, V, mask=None):
    # Q,K,V: (batch, heads, seq, d_k)
    d_k = Q.size(-1)
    scores = Q @ K.transpose(-2, -1) / (d_k ** 0.5)   # (b, h, seq, seq)
    if mask is not None:
        scores = scores.masked_fill(mask == 0, float('-inf'))
    attn = F.softmax(scores, dim=-1)
    return attn @ V, attn                              # (b, h, seq, d_k)
```

要点：除 √d_k；mask 用 -inf 让 softmax 后为 0；softmax 沿最后一维（key）。

## 2. Multi-Head Attention

```python
import torch.nn as nn

class MultiHeadAttention(nn.Module):
    def __init__(self, d_model, n_heads):
        super().__init__()
        assert d_model % n_heads == 0
        self.h, self.d_k = n_heads, d_model // n_heads
        self.qkv = nn.Linear(d_model, 3 * d_model)
        self.out = nn.Linear(d_model, d_model)

    def forward(self, x, mask=None):
        B, T, C = x.shape
        qkv = self.qkv(x).reshape(B, T, 3, self.h, self.d_k).permute(2, 0, 3, 1, 4)
        q, k, v = qkv[0], qkv[1], qkv[2]               # (B, h, T, d_k)
        att = (q @ k.transpose(-2, -1)) / (self.d_k ** 0.5)
        if mask is not None:
            att = att.masked_fill(mask == 0, float('-inf'))
        att = att.softmax(-1)
        y = (att @ v).transpose(1, 2).reshape(B, T, C) # 合并多头
        return self.out(y)
```

要点：reshape 拆头 → 算注意力 → transpose 回来合并 → 输出投影。

## 3. Layer Normalization

```python
def layer_norm(x, gamma, beta, eps=1e-5):
    # x: (..., d), 在最后一维归一化
    mean = x.mean(-1, keepdim=True)
    var = x.var(-1, keepdim=True, unbiased=False)
    return gamma * (x - mean) / (var + eps).sqrt() + beta
```

对比 BatchNorm：LN 对单样本特征维归一化，与 batch 无关，适合变长序列。

## 4. 因果掩码（causal mask）

import torch
def causal_mask(T):
    # 下三角为 1（可见），上三角为 0（屏蔽未来）
    return torch.tril(torch.ones(T, T)).bool()

## 6. 一步 REINFORCE / 策略梯度更新

```python
# 策略梯度核心: loss = -(log_prob * advantage).mean()
def policy_gradient_loss(log_probs, returns):
    # returns 可用 (R - baseline) 做优势
    advantages = returns - returns.mean()
    return -(log_probs * advantages.detach()).mean()
```

要点：最大化 期望回报 ⇒ 最小化 负的 (log 概率 × 优势)；优势降方差。

## 7. 简化版 PPO clipped 目标

```python
def ppo_loss(log_prob, old_log_prob, advantage, eps=0.2):
    ratio = (log_prob - old_log_prob).exp()
    unclipped = ratio * advantage
    clipped = ratio.clamp(1 - eps, 1 + eps) * advantage
    return -torch.min(unclipped, clipped).mean()
```

要点：clip 概率比，取 min 保证保守更新，防止策略剧变。

## 8. KMeans（经典 ML 手撕）

```python
import numpy as np
def kmeans(X, k, iters=100):
    centers = X[np.random.choice(len(X), k, replace=False)]
    for _ in range(iters):
        d = ((X[:, None] - centers[None]) ** 2).sum(-1)  # (N,k)
        labels = d.argmin(1)
        new = np.array([X[labels == j].mean(0) if (labels==j).any()
                        else centers[j] for j in range(k)])
        if np.allclose(new, centers):
            break
        centers = new
    return labels, centers
```
