# 具身智能 & 大模型 面试培训仓库

> 面向「具身智能（Embodied AI）+ 大模型（LLM / 多模态 / VLA）」方向求职的系统化面试准备资料库。
> 目标：把零散的知识点结构化为「能讲清楚、能手撕、能回答追问」的面试能力。

---

## 📌 这个仓库解决什么问题

具身智能 + 大模型 是一个交叉方向，面试通常会同时考察：

1. **大模型基础**：Transformer / 注意力机制 / 预训练 / 微调对齐（SFT、RLHF、DPO）/ 推理优化
2. **多模态与 VLA**：视觉编码、图文对齐、Vision-Language-Action 模型
3. **具身智能本体**：模仿学习、强化学习、Diffusion Policy、Sim2Real、机器人控制
4. **工程与系统**：分布式训练、推理部署、数据管线
5. **软技能**：项目复盘（STAR）、研究品味、对前沿的判断

本仓库按上述维度组织，每个知识点都尽量做到 **「概念 → 原理 → 面试问法 → 参考答案 → 追问陷阱」** 五段式。

## 🚀 使用建议

- **第一遍（建体系）**：按 `01 → 02 → 03` 顺序通读，建立知识地图，不求记住细节。
- **第二遍（练表达）**：对照 `04-高频面试题`，每题先合上答案自己讲一遍，再对照参考答案补漏。
- **第三遍（抠追问）**：重点看每个知识点末尾的「追问陷阱」，这是区分背诵和理解的地方。
- **持续维护**：把自己真实面试遇到的题、答得不好的点，回填到对应文件，形成个人错题本。

## ✅ 自测标准

能脱稿、不看资料、用 2-3 分钟向一个外行讲清楚下面任意一题，才算过关：

- 为什么 Attention 要除以 √d_k？
- RLHF 和 DPO 的本质区别是什么？
- KV Cache 解决了什么问题，代价是什么？
- 模仿学习的 distribution shift 问题怎么缓解？
- Diffusion Policy 相比直接回归动作好在哪？
- Sim2Real 的 gap 主要来自哪里，怎么缩小？
