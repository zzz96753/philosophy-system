## 三条阅读路径

### 路径A：人生规划路径

适合思考人生方向、职业选择、个人成长的读者。

```
入门通俗读物
  → 古希腊（斯多葛、伊壁鸠鲁、亚里士多德德性伦理）
  → 儒家（修身齐家、知行合一）
  → 道家（无为、逍遥）
  → 德国古典（尼采自我超越、康德道德律）
  → 存在主义（萨特自由、加缪反抗）
  → 佛学（四圣谛、无常）
  → ★ 哲学与人生规划（综合应用）
```

### 路径B：科学研究路径

适合研究者、博士生，关注方法论和学术思维。

```
入门通俗读物
  → 科学哲学（波普尔、库恩、拉卡托斯）
  → 近代哲学（理性主义vs经验主义、休谟因果问题）
  → 心灵哲学（AI意识、中文房间）
  → 认识论（JTB、葛梯尔问题、可靠主义）
  → ★ 哲学与科学研究方法论（深度方法论）
  → ★ 当代哲学与科技前沿（AI哲学、技术哲学）
  → 哲学与AI研究的交叉
```

### 路径C：全面素养路径

适合系统学习哲学、追求全面教养的读者。

```
入门通俗读物
  → 西方哲学史主线（古希腊→中世纪→近代→德国古典→现代）
  → 东方哲学传统（儒→道→佛→印度）
  → ★ 东西方哲学比较与融合
  → 专题选修（科学哲学/伦理学/政治哲学/美学/逻辑学）
  → ★ 哲学与人生规划 + ★ 当代哲学与科技前沿
```
