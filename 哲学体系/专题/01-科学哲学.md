# 科学哲学

> 科学是什么？科学方法可靠吗？科学知识的本质是什么？

---

## 核心问题

1. **划界问题**：科学与伪科学的界限在哪？
2. **归纳问题**：从有限观察能推出普遍规律吗？
3. **理论变迁**：科学进步还是科学革命？
4. **实在论争论**：科学理论描述的是真实世界吗？

---

## 逻辑实证主义

**维也纳学派**（1920s-1930s）

**核心主张**：
- **证实原则**：有意义的命题必须可由经验证实
- 形而上学命题无意义
- 科学 = 有意义知识的典范
- 分析命题（逻辑）+ 综合命题（经验）= 所有有意义的命题

**代表人物**：卡尔纳普、石里克、纽拉特

**问题**：
- 证实原则本身不可证实
- 全称命题无法被有限经验证实
- 过于严格，排除了太多有意义的陈述

## 波普尔的证伪主义

**卡尔·波普尔**（1902-1994）

### 核心思想

**科学理论的标准不是可证实，而是可证伪**

| 概念 | 说明 |
|------|------|
| 可证伪性 | 科学理论必须能被经验反驳 |
| 大胆猜想 | 好理论做出冒险的预测 |
| 严格检验 | 尝试推翻理论而非确认 |
| 暂时接受 | 未被证伪的理论暂时被接受 |

### 划界标准

- **科学**：可证伪（如"所有天鹅是白的"→ 发现黑天鹅即证伪）
- **伪科学**：不可证伪（如占星术、精神分析）
  - 什么结果都能解释 = 什么都没解释

### 科学进步

```
问题 → 大胆猜想 → 严格检验 → 排除错误 → 新问题 → ...
```

### 对AI研究的启示

- 你的模型/理论可以被证伪吗？
- 什么实验结果会推翻你的假设？
- 避免"怎么解释都行"的万能理论
- Benchmark 刷分 vs 真正的科学检验

**推荐**：《猜想与反驳》《科学发现的逻辑》

## 库恩的范式理论

**托马斯·库恩**（1922-1996）

### 《科学革命的结构》

**科学发展不是线性积累，而是革命性的范式转换**

### 核心概念

#### 范式（Paradigm）
- 共同体共享的信念、方法、标准
- 例：牛顿力学、量子力学、深度学习

#### 科学发展模式
```
前范式 → 常规科学 → 异常积累 → 危机 → 革命 → 新范式 → 新的常规科学
```

#### 常规科学
- 在范式内"解谜"
- 不质疑基本假设
- 类比：在深度学习范式内调参、改架构

#### 异常与危机
- 范式无法解释的现象积累
- 对基本假设的怀疑
- 例：深度学习的可解释性问题、鲁棒性问题

#### 不可通约性
- 不同范式无法直接比较
- 概念含义不同
- 看世界的方式不同

### 对AI研究的启示

- 深度学习是当前AI范式
- 符号AI是前一个范式
- 当前异常：幻觉、推理不足、缺乏因果理解
- 下一个范式是什么？神经符号融合？

**推荐**：《科学革命的结构》（**必读**）

## 拉卡托斯的研究纲领

**伊姆雷·拉卡托斯**（1922-1974）

### 调和波普尔与库恩

| 概念 | 说明 |
|------|------|
| 硬核 | 核心假设，不轻易放弃 |
| 保护带 | 辅助假设，可以调整 |
| 正面启发 | 指导如何发展理论 |
| 反面启发 | 禁止攻击硬核 |

### 进步 vs 退化

- **进步的研究纲领**：预测新事实，不断被验证
- **退化的研究纲领**：只是事后解释，没有新预测

### 对AI研究的启示

- 深度学习的"硬核"：可微分计算、梯度下降、大数据
- "保护带"：新架构（Transformer）、新训练方法
- 是进步的还是退化的？

## 费耶阿本德的无政府主义

**保罗·费耶阿本德**（1924-1994）

### "怎么都行"（Anything goes）

- 不存在唯一正确的科学方法
- 科学进步往往违反方法论规则
- 伽利略的成功部分靠修辞和宣传
- 科学不应该享有特权地位

### 价值

- 警惕科学方法论的教条化
- 承认科学实践的多样性
- 挑战科学至上主义

## 科学实在论争论

### 科学实在论

- 科学理论（大致）描述真实世界
- 电子、基因等理论实体真实存在
- 科学进步 = 越来越接近真理

### 反实在论 / 工具主义

- 理论只是预测工具
- 不必关心理论实体是否"真实"
- 关键是"经验充分性"

### 与AI的关联

- 神经网络是实在论的还是工具主义的？
- 模型学到的"表征"反映真实世界吗？
- 还是只是统计捷径？

---

## 贝叶斯主义科学哲学

### 核心思想

- 用概率表达信念程度
- 新证据 → 更新概率（贝叶斯定理）
- 科学推理 = 贝叶斯更新

### 与ML的关系

- 贝叶斯学习直接体现这一哲学
- 先验 = 先验知识/归纳偏置
- 后验 = 学习后的信念
- 连接哲学与机器学习
