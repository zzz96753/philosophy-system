# 逻辑学与语言哲学

> 如何正确思考？语言与世界的关系是什么？

---

## 第一部分：逻辑学

### 为什么学逻辑？

- 训练清晰思考的能力
- 识别错误论证
- 编程和数学的基础
- AI/形式化推理的核心

---

### 古典逻辑

#### 亚里士多德的三段论

- 西方逻辑学的起点
- 演绎推理的标准形式

**基本结构**：
```
大前提：所有人都会死
小前提：苏格拉底是人
结论：  苏格拉底会死
```

#### 基本概念

| 概念 | 说明 | 例子 |
|------|------|------|
| 命题 | 可以判断真假的陈述 | "雪是白的" |
| 前提 | 论证的出发点 | 大前提、小前提 |
| 结论 | 从前提推出的命题 | |
| 有效性 | 形式正确（前提为真则结论必为真）| |
| 可靠性 | 有效 + 前提实际为真 | |

### 现代形式逻辑

#### 命题逻辑

**基本联结词**：

| 符号 | 名称 | 含义 |
|------|------|------|
| ~   | 否定 | 非p |
| ∧ | 合取 | p且q |
| ∨ | 析取 | p或q |
| → | 蕴含 | 如果p则q |
| ↔ | 等值 | p当且仅当q |

#### 谓词逻辑

- 全称量词 ∀：对所有x
- 存在量词 ∃：存在某个x
- 例：∀x(Human(x) → Mortal(x)) — 所有人都会死

#### 弗雷格的贡献

- 现代逻辑之父
- 发明了谓词逻辑
- 区分"意义"（Sinn）和"指称"（Bedeutung）
  - "晨星"和"暮星"指称相同（金星），但意义不同

### 常见逻辑谬误

| 谬误 | 说明 | 例子 |
|------|------|------|
| 人身攻击 | 攻击论者而非论点 | "你又不是专家" |
| 稻草人 | 歪曲对方立场再反驳 | |
| 诉诸权威 | 因为专家说所以正确 | |
| 滑坡谬误 | 无根据的连锁推论 | "允许A就会导致Z" |
| 循环论证 | 用结论证明前提 | "圣经是真的因为它是上帝的话" |
| 虚假两难 | 只给两个选项（其实有更多）| "要么支持我，要么反对我" |
| 诉诸情感 | 用情感代替论证 | |
| 以偏概全 | 从个例推普遍 | |

| 相关非因果 | 相关不等于因果 | "冰淇淋销量↑ → 溺水↑" |

### 哥德尔不完备定理

**库尔特·哥德尔**（1906-1978）

**第一不完备定理**：
> 任何足够强的一致形式系统，都存在不可证明也不可反驳的真命题

**第二不完备定理**：
> 一致的形式系统无法证明自身的一致性

**意义**：
- 数学不可能完全形式化
- 真理超出可证明性
- 对AI的启示：形式系统有根本局限

## 第二部分：语言哲学

### 核心问题

1. **意义**：词语如何有意义？
2. **指称**：语言如何与世界关联？
3. **真理**：什么使命题为真？
4. **言语行为**：说话是在做什么？

---

### 意义理论

#### 指称论
- 词语的意义 = 它所指的对象
- 问题："独角兽"指什么？

#### 观念论
- 意义 = 与词语关联的心理观念
- 问题：观念是私有的，如何沟通？

#### 用法论（维特根斯坦后期）
- **意义在于使用**
- 语言游戏：不同语境下词语有不同用法
- 没有固定本质，只有家族相似

#### 真值条件论
- 理解句子的意义 = 知道使它为真的条件
- "雪是白的"为真，当且仅当雪是白的
- 戴维森、塔斯基

---

### 维特根斯坦

#### 早期：《逻辑哲学论》

- 语言是世界的图像
- 命题是事态的逻辑图像
- "凡能说的，都能说清楚；凡不能说的，就应当沉默"
- 哲学问题 = 语言的误用

#### 后期：《哲学研究》

- **推翻自己的早期思想**
- 语言不是图像，而是工具
- **语言游戏**：语言在不同活动中的使用
- **家族相似**：概念之间没有共同本质
- **私有语言论证**：纯粹私有的语言不可能
- **意义即使用**

**推荐**：《哲学研究》

---

### 言语行为理论

**奥斯汀 & 塞尔**

#### 核心洞见：说话就是做事

**三种行为**：

| 行为 | 说明 | 例子 |
|------|------|------|
| 语谓行为 | 说出有意义的话 | 说出"窗户开着" |
| 语旨行为 | 说话的意图 | 请求关窗 |
| 语效行为 | 说话的效果 | 对方去关窗 |

**言语行为类型**：
- 断言（陈述事实）
- 指令（请求、命令）
- 承诺（保证、发誓）
- 表达（感谢、道歉）
- 宣告（宣布、命名）

**与AI的关系**：
- 理解用户意图 = 理解言语行为
- 对话系统需要超越字面意义
- 语用学对NLP的重要性

---

### 语言与思维

#### 萨丕尔-沃尔夫假说

- **强版本**：语言决定思维
- **弱版本**：语言影响思维
- 例：因纽特语有多个词表示"雪" → 对雪的感知更精细？

#### 思维语言假说（福多）

- 思维以"心理语言"进行
- 不同于自然语言
- 先有思维，后有语言

#### 与AI的关系

- LLM用语言"思考" → 语言是思维的充分基础吗？
- 没有非语言经验 → 理解有局限？
- 多语言模型 → 不同语言的影响
