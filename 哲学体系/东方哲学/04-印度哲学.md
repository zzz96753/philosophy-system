# 印度哲学

> 与中国哲学并列的东方两大哲学传统，深刻影响佛教和现代瑜伽

---

## 历史分期

```
吠陀时期 → 奥义书时期 → 沙门运动（佛教、耆那教）→ 六派哲学 → 中世纪 → 近现代
```

## 吠陀与奥义书

### 吠陀（约前1500-前500年）

- 印度最古老的文献
- 四部吠陀：《梨俱吠陀》《娑摩吠陀》《夜柔吠陀》《阿闼婆吠陀》
- 早期多神论，祭祀为核心
- 宇宙起源的追问（《造物赞歌》）

### 奥义书（约前800-前200年）

**关键词**：梵我一如、轮回、解脱

**核心思想**：

#### 梵（Brahman）
- 宇宙的终极实在、最高原理
- 无形无相、不可言说
- "非此、非此"（neti neti）— 通过否定来接近

#### 我（Atman）
- 个人的真实自我/灵魂
- 不同于身体和心理活动
- 永恒不变

#### 梵我一如（Tat tvam asi）
> "你就是那个"（That thou art）

- 个体的真我（Atman）= 宇宙的本体（Brahman）
- 认识到这一点即获得解脱（moksha）
- 无明（avidya）= 不知道梵我一如

#### 轮回与业力
- 灵魂在不同生命中流转
- 业（karma）决定下一世的状态
- 解脱 = 跳出轮回

**推荐**：《奥义书》选读（商务印书馆）

## 六派哲学（正统派）

承认吠陀权威的六大学派：

| 学派 | 核心关注 | 核心概念 |
|------|----------|----------|
| **数论**（Samkhya）| 宇宙构成 | 神我（purusha）与原质（prakriti）二元 |
| **瑜伽**（Yoga）| 修行解脱 | 八支瑜伽、禅定、心灵控制 |
| **正理**（Nyaya）| 逻辑与认识论 | 四种有效认知手段 |
| **胜论**（Vaisheshika）| 自然哲学 | 原子论、六种范畴 |
| **弥曼差**（Mimamsa）| 吠陀诠释 | 祭祀与行为的意义 |
| **吠檀多**（Vedanta）| 终极实在 | 梵我关系、世界本质 |

### 数论（Samkhya）

- **二元论**：神我（纯意识）与原质（物质根本）
- 宇宙由原质演化而来
- 解脱 = 神我认识到自己与原质的区别
- 影响了瑜伽和佛教

### 瑜伽（Yoga）

**帕坦伽利《瑜伽经》**：

**八支瑜伽**：
1. 持戒（yama）— 不杀、不妄语等
2. 内修（niyama）— 清净、知足等
3. 体式（asana）— 身体姿势
4. 调息（pranayama）— 呼吸控制
5. 制感（pratyahara）— 收摄感官
6. 专注（dharana）— 集中注意力
7. 禅定（dhyana）— 持续专注
8. 三摩地（samadhi）— 与对象合一

> 现代瑜伽多关注第3支（体式），原始瑜伽的核心是心灵修炼

### 吠檀多（Vedanta）— 最重要的学派

#### 商羯罗（约788-820）— 不二论

- **梵是唯一的实在**
- 世界是幻（maya）
- 个体灵魂与梵无本质区别
- 类比：绳上之蛇（误认绳为蛇 = 无明）

#### 罗摩努阇（1017-1137）— 限定不二论

- 梵是有属性的（有人格的神）
- 灵魂和世界真实存在，但依赖于梵
- 虔诚（bhakti）是解脱之路

## 正统六派详解

### 正理派（Nyaya）——印度的逻辑学

正理派是印度哲学中最重视逻辑和认识论的学派，由足目（Aksapada Gautama）的《正理经》（Nyaya Sutra）奠基。

**十六范畴**（padarthas）：
正理派建立了一个包含十六个范畴的完整辩论体系，其中最重要的包括：
- **量**（pramana）——有效认知手段
- **所量**（prameya）——认知对象
- **疑**（samsaya）——怀疑
- **目的**（prayojana）——辩论的目的
- **喻**（drstanta）——实例

**四种量（有效认知）**：

| 量 | 梵文 | 说明 |
|----|------|------|
| 现量 | pratyaksa | 直接感知——感官与对象的接触 |
| 比量 | anumana | 推理——见烟知火 |
| 类比量 | upamana | 类比——通过已知认识未知 |
| 声量 | sabda | 证言——可靠权威的言语 |

**印度逻辑的五支论式**：

1. **宗**（pratijna）：此山有火（论题）
2. **因**（hetu）：因为有烟（理由）
3. **喻**（udaharana）：凡有烟处有火，如厨房（例证）
4. **合**（upanaya）：此山亦如是（应用）
5. **结**（nigamana）：故此山有火（结论）

**与亚里士多德逻辑的比较**：
- 亚里士多德的三段论是演绎逻辑，从普遍到特殊
- 正理派的五支论式兼有归纳和演绎，更接近实际推理过程
- 正理派更强调"实例"的作用——逻辑推理必须有经验基础

### 数论派（Samkhya）——宇宙的二元构成

**二十五谛（tattvas）**：

数论派将一切实在归结为二十五个基本原理：

```
神我（Purusha）— 纯意识、观照者

原质（Prakriti）— 物质世界的根本
  └─ 大（Mahat/Buddhi）— 智慧/觉识
      └─ 我慢（Ahamkara）— 自我意识
          ├─ 意（Manas）— 心意
          ├─ 五知根 — 眼耳鼻舌身
          ├─ 五作根 — 语手足排泄生殖
          ├─ 五唯 — 声触色味香
          └─ 五大 — 空风火水地
```

**三德（Gunas）**：

原质由三种基本属性构成：

| 德 | 梵文 | 特征 | 对应 |
|----|------|------|------|
| 萨埵 | sattva | 光明、轻盈、喜悦 | 智慧、清净 |
| 罗阇 | rajas | 活动、激情、不安 | 欲望、行动 |
| 答摩 | tamas | 黑暗、沉重、惰性 | 无知、懒惰 |

- 一切物质现象都是三德以不同比例混合的结果
- 当三德达到完美平衡时，宇宙处于未显现状态（原质）
- 当平衡被打破时，宇宙开始演化

**与笛卡尔二元论的比较**：
- 两者都主张精神（神我/心灵）与物质（原质/广延）是两种根本不同的实在
- 笛卡尔的问题：心灵如何影响身体？（松果体理论）
- 数论的回答：神我不影响原质——它只是观照；原质在神我面前自行展开（类似舞者在观众面前表演）

### 瑜伽派（Yoga）——意识哲学与修行体系

**帕坦伽利的意识哲学**：

瑜伽不仅是身体练习，更是一套完整的意识哲学：

> "瑜伽即控制心念的波动"（yogas citta-vrtti-nirodhah）

- **心念波动**（vrtti）：意识不断产生的波动——认知、错误认知、想象、睡眠、记忆
- **控制**（nirodha）：不是压抑，而是让波动自然平息
- 当心念波动停止时，"观照者安住于自性"——纯粹意识显现

**三摩地的层次**：

| 类型 | 特征 |
|------|------|
| 有想三摩地 | 意识仍有对象——专注于某个目标 |
| 无想三摩地 | 意识超越对象——纯粹觉知 |
| 法云三摩地 | 最高境界——智慧如云降雨 |

**现代科学研究**：
- 神经科学研究表明，长期冥想者的大脑结构确实发生了改变（前额叶皮层增厚、杏仁核活动减少）
- fMRI研究显示，冥想状态下的大脑活动模式与日常状态显著不同
- 但瑜伽哲学所描述的"纯粹意识"状态是否真正可能，仍然是一个开放的科学和哲学问题

### 胜论派（Vaisheshika）——印度的原子论

胜论派由迦那陀（Kanada）创立，是印度哲学中最接近自然科学的学派。

**七种范畴**（padarthas）：

| 范畴 | 梵文 | 说明 |
|------|------|------|
| 实 | dravya | 实体——地、水、火、风、空、时、方、我、意 |
| 德 | guna | 性质——颜色、味道、气味等 |
| 业 | karma | 运动 |
| 同 | samanya | 普遍性 |
| 异 | vishesha | 特殊性 |
| 和合 | samavaya | 固有关系 |
| 无 | abhava | 非存在 |

**原子论**：
- 物质世界由不可分割的原子（anu/paramanu）构成
- 地、水、火、风各有其原子
- 原子是永恒的，但原子的组合是无常的
- 两个原子结合形成"双原子"（dvyanuka），三个双原子形成"三原子"（tryanuka），由此逐步构成可感知的物体

**与德谟克利特原子论的比较**：
- 两者都独立发展出了原子理论——这是人类思想史上的惊人巧合
- 德谟克利特的原子只有大小、形状差异；胜论派的原子还有性质差异（地原子有味，火原子有色等）
- 德谟克利特是唯物论者；胜论派承认灵魂（我）的存在

### 弥曼差派（Mimamsa）——语言与仪式的哲学

弥曼差派由阇弥尼（Jaimini）创立，主要关注吠陀经典的诠释学：

**语言哲学**：
- **声常住论**：语言（声音）不是被创造的，而是永恒存在的——人的发音只是"显现"了永恒的声音
- **语义关系的内在性**：词与义之间的关系不是人为约定的，而是天然固有的
- 这与索绪尔（Saussure）的"任意性"原则形成鲜明对比

**法（Dharma）作为宇宙秩序**：
- 法不仅是道德律令，更是宇宙的内在秩序
- 正确执行仪式就是与宇宙秩序保持一致
- 仪式不是迷信，而是人与宇宙秩序之间的实践性连接

**仪式诠释学**：
- 发展了一套精密的文本诠释方法——如何正确理解吠陀中的仪式指令
- 这些诠释原则后来被印度法学广泛采用

### 吠檀多派（Vedanta）——终极实在的三种阐释

吠檀多是印度哲学中影响最深远的学派，内部有三个主要分支：

**不二论（Advaita）——商羯罗**：
- 梵是唯一的实在，世界是幻（maya），个体灵魂与梵无本质区别
- "梵实世幻"——这是最激进的一元论立场
- 解脱之道：知识（jnana）——认识到梵我一如
- 商羯罗使用"上下梵"区分：无属性梵（nirguna brahman）是终极实在，有属性梵（saguna brahman）是为了方便教化

**限定不二论（Vishishtadvaita）——罗摩努阇**：
- 梵是有属性的最高实在（等同于毗湿奴神）
- 灵魂和世界真实存在，但作为梵的"属性"或"部分"而存在
- 梵、灵魂、世界三者构成一个有机整体——如身体与灵魂的关系
- 解脱之道：虔诚（bhakti）——通过爱和信仰达到与神的合一

**二元论（Dvaita）——摩陀婆**：
- 梵（神）与灵魂是根本不同的两种实在
- 灵魂永远不可能"成为"梵——只能通过虔诚获得神的恩宠
- 世界和灵魂都是真实的，不是幻
- 这是印度哲学中最接近基督教有神论的立场

**梵我辩论的哲学意义**：
这三种立场实际上代表了形而上学中的三种基本可能：
- 一元论：一切归于一（商羯罗）
- 有机整体论：多样性在统一中（罗摩努阇）
- 二元/多元论：多种实在并存（摩陀婆）

## 非正统派

不承认吠陀权威：

### 佛教
- 见 [佛学](03-佛学.md) 专篇
- 否认永恒自我（无我论）
- 与印度教的根本分歧

### 耆那教

**关键词**：非暴力、多面论、苦行

- **非暴力**（ahimsa）：极端避免伤害一切生命
- **多面论**（anekantavada）：真理有多个面向
  - 盲人摸象的比喻
- 灵魂（jiva）被业力物质束缚
- 通过苦行净化灵魂
- 影响了甘地的非暴力思想

### 顺世论（Charvaka）

- 印度的唯物主义学派
- 只承认感知为有效认知
- 否认灵魂、轮回、来世
- 追求现世快乐
- 印度哲学中的"异类"

## 非正统派系深入

### 顺世派（Charvaka/Lokayata）——印度唯物主义

顺世派是人类思想史上最早的系统唯物主义哲学之一，其历史可追溯至公元前6世纪：

**核心主张**：
- **唯物论**：只有地、水、火、风四大元素是真实的。意识不过是四大元素以特定方式组合的产物——"如同酒精由发酵的谷物产生"
- **感觉论**：只承认感知（现量）为有效认知手段，拒绝推理、类比和证言
- **享乐主义**："在活着的时候享受快乐"——死后什么都没有
- **反仪式**：祭祀和苦行都是骗局——"如果杀牲能使被杀者升天，为什么祭祀者不杀自己的父亲？"

**哲学意义**：
- 顺世派证明了印度哲学并非只有宗教和灵性——它也有彻底的唯物主义和世俗主义传统
- 作为其他学派的"反面"，顺世派迫使所有学派加强了自己的论证——推动了印度哲学的精密化
- 与古希腊的伊壁鸠鲁学派和中国的杨朱学派有结构上的相似

### 耆那教哲学——多面性与非暴力

耆那教不仅是一种宗教，更是一种深刻的哲学体系：

**多面论（Anekantavada）——真理的多面性**：
- 一切事物都有无限多的面向（ananta-dharma）
- 任何一个有限的视角都只能把握真理的一个面向
- 因此，对任何事物的判断都应该是"在某种意义上"（syat）——这就是"或然论"（syadvada）

**七支断言（Saptabhangi）**：
对任何命题X，耆那教认为可以做出七种合法断言：
1. 在某种意义上，X 是
2. 在某种意义上，X 不是
3. 在某种意义上，X 既是又不是
4. 在某种意义上，X 不可言说
5. 在某种意义上，X 是且不可言说
6. 在某种意义上，X 不是且不可言说
7. 在某种意义上，X 既是又不是且不可言说

**非暴力（Ahimsa）作为形而上学原则**：
- 耆那教的非暴力不仅是伦理规范，更有形而上学基础——一切存在物（包括植物、水、空气中的微生物）都有灵魂（jiva）
- 因此，任何暴力行为都是对灵魂的伤害
- 极端的耆那教修行者在走路时扫地（避免踩死昆虫），戴口罩（避免吸入微生物），过滤饮水
- 这种对一切生命的极端尊重在人类思想史上独一无二

**耆那教逻辑的现代意义**：
- 多面论提供了一种超越二元对立的思维方式——在多元文化时代尤为重要
- 或然论要求对一切判断保持谦逊——"我的观点可能只是真理的一个面向"
- 这与当代科学哲学中的"视角实在论"（perspectival realism）有深刻共鸣

## 印度语言哲学

### 跋奢利哈里（Bhartrhari，约5世纪）——声即梵

跋奢利哈里提出了印度哲学中最重要的语言哲学理论——声论（sphota）：

**声论（Sphota Theory）**：
- **sphota**（字面意思"爆裂"、"显现"）：词的意义不是由一个个声音逐渐积累而成的，而是在听到所有声音后突然"爆裂"式地整体显现
- 语言不是意义的工具，而是意义本身——"声即梵"（sabda-brahman）
- 语言是终极实在（梵）的本质表现形式

**语言与实在的三层结构**：
| 层次 | 名称 | 特征 |
|------|------|------|
| 观照层 | pasyanti | 未分化的意义——思想尚未分化为词语 |
| 中间层 | madhyama | 内在语言——思维中的语言 |
| 显现层 | vaikhari | 外在语言——发出的声音 |

**与索绪尔的比较**：
- 索绪尔：语言符号是能指（signifier）和所指（signified）的任意结合
- 跋奢利哈里：语言与意义之间的关系不是任意的，而是内在的——语言是意义的自然显现
- 索绪尔强调语言的社会约定性；跋奢利哈里强调语言的本体论地位

### 波你尼（Panini，约前4世纪）——语法即哲学

波你尼的《八章书》（Astadhyayi）包含近4000条语法规则，是人类历史上最精密的语法体系之一：

- 波你尼的语法不仅是语言描述，更是一种形式化的思维方式
- 他使用了元语言、递归规则、变换规则等——这些概念在20世纪才被乔姆斯基（Chomsky）重新"发现"
- 乔姆斯基的生成语法与波你尼的语法体系有深刻的结构相似性

## 克什米尔湿婆派

### 辨识哲学（Pratyabhijna）

克什米尔湿婆派（Kashmir Shaivism）是印度哲学中最精密的非二元论体系之一，由乌特帕拉提婆（Utpaladeva）和阿毗那婆笈多（Abhinavagupta，约950-1020）发展至巅峰。

**辨识（Pratyabhijna）**：
- 字面意思是"再次认识"——觉悟不是获得新知识，而是重新认识到本来就有的东西
- 一切意识都是湿婆（最高意识）的自我显现——个体意识只是湿婆意识的一个面向
- 解脱就是认识到"我就是湿婆"——不是道德完善，而是认识论的转变

**三十六谛（tattvas）**：

克什米尔湿婆派将数论的二十五谛扩展为三十六谛：
- 在原质和神我之上，增加了纯粹意识的层次
- **湿婆**（第36谛）——纯粹意识、绝对自由
- **夏克提**（第35谛）——意识的创造力
- **五铠甲**（kancukas）——限制纯粹意识的五层覆盖：有限的行动力、有限的知识、有限的欲望、时间、因果

**振动论（Spanda）**：
- 宇宙的本质是"振动"（spanda）——纯粹意识的脉动
- 这不是物理学意义上的振动，而是意识在自身内部的展开和收回
- 一切现象都是这个原初振动的不同频率和模式

**审美意识理论**：
阿毗那婆笈多将辨识哲学与审美理论结合，提出了印度美学的巅峰理论：
- **味**（rasa）：审美体验中的极乐不是普通的快感，而是意识回归自身的一个瞬间
- 在审美体验中，自我意识（我慢）暂时消融——观众不再是"个体"，而是纯粹的意识
- 这种理论将美学与形而上学、修行统一了起来

## 深度思考：印度智慧与现代生活

### 瑜伽哲学：超越体式

- 现代瑜伽几乎等同于体式（asana）练习，但帕坦伽利的瑜伽是一个完整的八支体系——体式只是第三支
- 瑜伽的核心是"心念的控制"——在信息过载的时代，这种注意力训练比以往任何时候都更重要
- 帕坦伽利的"不执着"（vairagya）与现代正念运动的"不判断"有深刻共鸣——两者都要求对内在体验保持觉知而不做反应

### 冥想作为哲学实践

- 印度哲学不是纯粹的理论思辨——它要求通过修行来验证哲学洞见
- "三摩地"不仅是宗教体验，更是一种认识论方法——通过改变意识状态来获得不同的知识
- 当代认知科学家和哲学家已经开始认真对待"冥想作为方法论"这一想法——意识的第一人称研究

### 印度逻辑与批判性思维

- 正理派的五支论式提供了一个完整的论证框架——不仅有逻辑推理，还要求实例支持
- 耆那教的多面论教导我们：任何复杂问题都有多个合法的视角——一方面的正确不意味着另一方面的错误
- 佛教的四句否定提醒我们：有些问题可能超越了"是或否"的框架——学会说"这个问题本身可能就是错误的"

### 耆那教的多面性与宽容

- 在宗教冲突和文化对立日益加剧的时代，耆那教的多面论（anekantavada）提供了一种珍贵的思维方式
- "在某种意义上，你是对的；在某种意义上，我也是对的"——这不是相对主义（不是说所有观点都等价），而是认识论的谦逊
- 非暴力不仅是对身体的，也包括对思想和言语的——"思想上的非暴力"意味着不用暴力手段否定他人的观点
