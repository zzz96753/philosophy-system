## 三、内容调性指南

### 写作原则

1. **清晰优先**：能用大白话说清楚的，绝不用术语装深奥
2. **先钩后教**：每篇开头用生活场景/问题/悖论钩住读者
3. **结构可见**：大量使用小标题、列表、表格——读者能快速扫描
4. **有用落地**：每篇末尾给出"今天就能用"的思维工具或练习
5. **诚实谦逊**：哲学没有标准答案，展示不同立场，不装权威

### 语言风格谱

```
学术论文 ←————————|——★——————→ 段子手
                   ↑
              我们在这里
         正式但不枯燥 · 专业但不装
```

### 语句示例

| ❌ 不要 | ✅ 要 |
|---------|-------|
| 笛卡尔的怀疑论方法论通过系统性的认识论审查… | 笛卡尔做了一件疯狂的事：他决定怀疑一切。 |
| 功利主义的核心原则是最大化总体效用函数… | 功利主义说：好的决策就是让最多人获益的决策。 |
| 此处应参考康德《纯粹理性批判》B版序言… | 康德自己说了一句大话：我要给哲学来一次"哥白尼革命"。 |

### 每篇内容的必备结构

```
1. 钩子（问题/故事/悖论/反常识）     ← 前3秒留人
2. 核心概念（用最简单的话解释）       ← 知识传递
3. 展开（论证/例子/对比/思想实验）    ← 深度理解
4. 生活连接（这跟你有什么关系？）     ← 价值感知
5. 思维工具/练习（今天就能用的东西）  ← 行动转化
6. 互动问题（留言/投票/讨论）         ← 用户参与
```

## 四、平台差异化策略

### 内容适配矩阵

| 维度 | 微信公众号 | 小红书 | B站 | 知乎 |
|------|-----------|--------|-----|------|
| 内容形态 | 长文（2000-4000字）| 图文卡片（6-9张）| 视频（8-15分钟）| 长回答/文章 |
| 核心功能 | 深度沉淀、体系化 | 引流、破圈、获客 | 深度讲解、人格化 | SEO、长尾流量 |
| 发布频率 | 每周2-3篇 | 每周4-5条 | 每周1-2条 | 每周2-3篇 |
| 语言风格 | 理性从容 | 亲和活泼、口语化 | 对话感、有人格 | 专业严谨 |
| 标题风格 | 清晰概括型 | 悬念/数字/反差 | 好奇/悬念 | 问题导向型 |
| 互动方式 | 留言精选 | 评论区互动 | 弹幕/评论 | 评论区讨论 |

### 各平台标题公式

**公众号**：
- `{哲学家}最重要的一个思想，能解决你的{生活问题}`
- `{哲学概念}：你每天都在用但不知道的思维工具`
- `{数字}个改变世界的哲学思想实验`

**小红书**：
- `学了{哲学概念}之后，我做决策再也没纠结过！`
- `{哲学家}要是活在今天，他会怎么看AI？`
- `哲学专业的人都在用的{数字}个思维技巧`

**B站**：
- `如果苏格拉底来审判ChatGPT…`
- `用{数字}分钟搞懂{哲学概念}——你绝对用得上`
- `{哲学家}有多狠？他怀疑了一切，只剩下这一句话`

**知乎**：
- 回答热门问题，植入哲学框架
- `如何评价{热点事件}？从{哲学理论}的角度分析`
- `{生活困惑}——{数字}位哲学家会给你什么建议？`

## 五、增长策略

### 冷启动（0-1000粉，1-3个月）

1. **知乎打底**：回答高流量哲学/思维相关问题，建立专业形象
2. **小红书测爆款**：批量测试短内容，找到爆款方向
3. **公众号沉淀**：每周稳定更新，建立内容资产
4. **B站起步**：月更1-2条精品视频

### 增长期（1000-10000粉，3-12个月）

1. **系列化**：打造3-4个固定系列，培养读者期待
2. **互推合作**：联系哲学/人文/AI领域的同等级账号互推
3. **热点借势**：用哲学框架解读社会热点
4. **读者共创**：征集问题，做"哲学家会怎么回答"系列

### 变现路径（远期规划）

```
免费内容（引流）→ 社群（粘性）→ 付费产品（变现）
                                    ├── 哲学思维训练营
                                    ├── 哲学通识课（视频）
                                    ├── 原典共读会（社群）
                                    └── 咨询/讲座（高端）
```
