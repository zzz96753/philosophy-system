## 一、内容体系架构

### 七大内容系列

从现有哲学知识库提炼出七条内容线，覆盖不同受众需求和平台特性：

| # | 系列名 | 内容来源 | 核心价值 | 主打平台 | 频率 |
|---|--------|----------|----------|----------|------|
| 1 | **思维工具箱** | 总览图·实用工具箱 | 每期教一个马上能用的哲学工具 | 小红书+公众号 | 周更2 |
| 2 | **哲学家列传** | 西方哲学5篇+东方4篇 | 有趣的人物故事+核心思想 | B站+公众号 | 周更1 |
| 3 | **东西对话** | 东西方比较专题 | 同一问题的东西方不同回答 | 公众号+知乎 | 双周1 |
| 4 | **AI×哲学** | 心灵哲学+AI交叉 | AI热点的哲学深度解读 | 知乎+B站 | 周更1 |
| 5 | **人生哲学课** | 人生规划专题 | 哲学如何帮你做人生决策 | 小红书+公众号 | 周更1 |
| 6 | **每日一问** | 全知识库 | 一个哲学问题引发思考和互动 | 小红书 | 日更 |
| 7 | **原典精读** | 推荐书单+专题 | 带读者啃经典，降低门槛 | 公众号+知乎 | 月更2 |

### 内容复用矩阵（一鱼多吃）

一份核心内容 → 4个平台的不同形态：

```
核心稿件（2000-3000字长文）
  │
  ├──→ 公众号：完整长文 + 精美排版
  │
  ├──→ 小红书：提炼为6-9张卡片 + 金句封面
  │
  ├──→ B站：改写为口语化脚本 → 录制/AI配音
  │
  ├──→ 知乎：拆分为2-3个问题回答 + 一篇专栏文章
  │
  └──→ 素材库：提炼金句 → 日常发布"每日一问"
```

## 二、各平台详细策略

### 微信公众号

**定位**：内容主阵地，深度内容沉淀

**内容规划**：
- 周二：思维工具箱 或 人生哲学课（实用类）
- 周四：哲学家列传 或 东西对话（知识类）
- 周六（可选）：AI×哲学 或 原典精读（深度类）

**排版规范**：
- 首行：金句引用（楷体/灰色）
- 正文：15px，行间距1.75，字间距0.5px
- 小标题：加粗，前后空行
- 插图：每1000字至少1张配图/表格/思维导图
- 文末：固定"思考练习"板块 + 引导语（关注/转发/留言）

**菜单栏设置**：
```
哲学入门          系列精选          关于我们
├── 从这里开始     ├── 思维工具箱    ├── 账号介绍
├── 学习路线图     ├── 哲学家列传    ├── 推荐书单
└── 概念速查       ├── AI×哲学      └── 合作联系
                   └── 原典精读
```

### 小红书

**定位**：引流入口，轻量化破圈

**内容类型**：
1. **知识卡片**（6-9张）：从长文提炼的精华，大字+配色
2. **思维工具单图**：一张图讲清一个哲学工具
3. **每日一问**：一张卡片提出哲学问题，引导互动
4. **哲学家名言**：金句+人物介绍+现代解读
5. **热点哲学解读**：用哲学框架分析热门事件

**发布节奏**：
- 周一三五：知识卡片/工具（从核心稿件拆分）
- 周二四：每日一问/金句
- 周六日（可选）：热点解读

**标签策略**：
```
必带标签：#哲学 #思维方式 #认知提升
辅助标签：#哲学入门 #批判性思维 #自我提升 #终身学习
话题标签：根据内容加 #存在主义 #斯多葛 #AI #东方哲学 等
```

### B站

**定位**：深度讲解，建立人格化品牌

**视频类型**：
1. **科普讲解**（8-15min）：一个哲学家/概念/思想实验的完整讲解
2. **哲学辩论**（10-20min）：正反方分析一个哲学争论
3. **热点解读**（5-10min）：用哲学回应当下热点
4. **哲学×AI**（10-15min）：AI相关哲学问题深度讨论

**发布频率**：周更1条（优先保证质量）

**视频结构模板**：
```
0:00 - 钩子（15秒内抛出核心问题/悖论）
0:15 - 引入（故事/场景/反常识）
1:00 - 核心概念解释
3:00 - 深入展开（思想实验/论证/例子）
6:00 - 生活连接（与你有什么关系）
8:00 - 反面/争议（不同观点）
10:00 - 总结 + 思维工具
11:00 - 互动问题 + 下期预告
```

### 知乎

**定位**：SEO长尾流量，专业形象建设

**内容策略**：
1. **回答高流量问题**：搜索"哲学""思维""AI意识"等关键词下的热门问题
2. **专栏文章**：从公众号稿件适配，更学术化
3. **想法/动态**：每日短内容，哲学思考碎片

**选择回答的标准**：
- 关注人数 > 500
- 回答数 < 50（竞争不太激烈）
- 问题与内容系列相关

**回答结构**：
```
一句话直接回答 ← 先给结论
───────────
详细展开      ← 然后论证
───────────
哲学背景      ← 增加深度
───────────
不同观点      ← 展示公正性
───────────
个人见解 + 引导关注 ← 建立品牌
```

## 三、内容生产工作流

### 周度工作流（建议8-10小时/周）

```
周日（2h）：选题规划
  ├── 确认本周4个平台的发布内容
  ├── 从选题库选题 → 确认核心稿件主题
  └── 准备素材（查阅知识库对应章节）

周一（2h）：核心稿件写作
  ├── 从知识库提取知识点
  ├── 撰写核心长文（2000-3000字）
  └── 完成公众号版本

周二（1.5h）：内容拆分
  ├── 公众号排版 → 发布
  ├── 提炼小红书卡片文案 + 设计
  └── 知乎版本适配

周三-周四（1.5h）：分发 + 互动
  ├── 小红书发布 + 评论区互动
  ├── 知乎发布 + 回答问题
  └── 收集用户反馈 → 更新选题库

周五（1h）：B站脚本
  ├── 将核心稿件改写为视频脚本
  └── 录制/剪辑（或使用AI工具）

周六（1h）：复盘 + 补充
  ├── 数据复盘（各平台表现）
  ├── 补发缺少的内容
  └── 更新知识库（学习新内容 → 反哺知识库）
```

### 从知识库到发布的转化流程

```
知识库原始文件
    │
    ▼
选题库选定主题 + 角度
    │
    ▼
核心稿件（Markdown草稿）
    │
    ├──→ 公众号排版（秀米/135编辑器）
    ├──→ 小红书卡片（Canva/创客贴）
    ├──→ B站脚本 → 录制/AI配音
    └──→ 知乎适配发布
    │
    ▼
发布后互动 → 用户问题反馈
    │
    ▼
更新知识库 · 补充选题库
```

## 六、知识库与自媒体的双向反哺

### 学习驱动内容

```
知识库学习进度 → 选题灵感
                   ↓
正在学的内容 → "学习笔记"式文章（最真实、最有共鸣）
刚搞懂的概念 → "终于搞懂了"式解读（最接地气）
读完一本书 → 书评/推荐（最有说服力）
```

### 内容反哺学习

```
写作过程发现知识漏洞 → 回去补充知识库
读者提问 → 新的研究方向
评论区讨论 → 深化理解
```

> **核心原则**：自媒体不是知识库的"搬运"，而是知识库的"压力测试"——如果你不能用大白话讲清楚一个概念，说明你还没真正理解它。
