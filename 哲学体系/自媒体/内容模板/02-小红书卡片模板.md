# 小红书内容模板

> 适用内容类型：知识卡片、思维工具单图、每日一问、哲学家名言、热点解读

---

## 一、知识卡片（6-9张）

### 卡片结构

```
【封面卡（第1张）】
┌─────────────────────────────┐
│                             │
│   系列色块标签               │
│   （如：🧠 思维工具箱）       │
│                             │
│   大标题（2行以内）           │
│   "苏格拉底产婆术"           │
│   "学会提问比学会回答更重要"   │
│                             │
│   小字：哲思实验室            │
└─────────────────────────────┘

【内容卡（第2-7张）】
┌─────────────────────────────┐
│  顶部：序号/小标题            │
│                             │
│  核心内容（大字）             │
│  · 每张卡片只讲1个要点        │
│  · 控制在50字以内             │
│  · 关键词加粗/变色            │
│                             │
│  底部：辅助说明或小图标        │
└─────────────────────────────┘

【总结卡（第8张）】
┌─────────────────────────────┐
│                             │
│   核心要点回顾（3-4条）       │
│   或：一句话总结金句          │
│                             │
│   "记住：定义→反例→矛盾→修正" │
│                             │
└─────────────────────────────┘

【互动卡（第9张）】
┌─────────────────────────────┐
│                             │
│   互动问题                   │
│   "你觉得自己最需要被追问的   │
│    概念是什么？"              │
│                             │
│   点赞 + 收藏 + 关注引导      │
│   哲思实验室 · 用哲学升级思维  │
└─────────────────────────────┘
```

### 设计规范

| 元素 | 规格 |
|------|------|
| 尺寸 | 1080×1440px（3:4竖版） |
| 封面字号 | 标题60-80pt，副标题30-40pt |
| 内容卡字号 | 主文字40-50pt，说明24-30pt |
| 配色 | 按系列色调（见VI手册） |
| 字体 | 思源黑体/思源宋体 |
| 每张文字量 | 不超过50字 |

### 文案范例

**封面**：
```
🧠 思维工具箱 #001

苏格拉底产婆术
——比任何思维课都管用的提问法
```

**正文文案（依次对应每张卡片）**：

卡片2：
```
01 什么是产婆术？

苏格拉底不直接给答案
而是通过连续追问
帮你把模糊的想法"生"出来

→ 他妈妈是助产士
   所以他管这叫"思想接生术"
```

卡片3：
```
02 四步提问法

① 请给出定义
  "你说的XX到底是什么？"

② 找出反例
  "那YY算不算？"

③ 暴露矛盾
  "你说A，但例子说明B"

④ 修正定义
  重新来过，逼近真相
```

卡片4-6（举例+应用+注意事项，略）

## 二、每日一问（单图卡片）

### 卡片结构

```
┌─────────────────────────────┐
│                             │
│   💭 每日一问 · Day 01       │
│                             │
│   ┌───────────────────┐     │
│   │                   │     │

│   │  "你怎么证明       │     │

│   │                   │     │

│   背景：笛卡尔·方法论怀疑    │
│   "我可以怀疑一切，            │
│    唯独不能怀疑我在怀疑"       │
```

### 设计规范

| 元素 | 规格 |
|------|------|
| 尺寸 | 1080×1080px（正方形）或 1080×1440px |

| 配色 | 统一使用"每日一问"系列色（浅青色系） |
| 风格 | 简洁留白，突出问题本身 |

## 四、标题与标签模板

### 标题公式（小红书版）

| 类型 | 公式 | 示例 |
|------|------|------|
| 反差型 | {看似简单的事}原来{反转} | 你以为的常识，其实是权力的产物🔍 |
| 数字型 | {数字}个{方法/原因/真相} | 12种逻辑陷阱，学完再也骗不到你🧠 |
| 挑战型 | {权威/常识}说错了？{真相} | 科学家花了2000年才解决这个古希腊难题🐢 |
| 实用型 | 学会这个{工具}，{效果} | 学会这个提问法，秒杀99%的思维陷阱💡 |
| 共鸣型 | {痛点场景}？{哲学解药} | 焦虑的时候试试这个2000年前的心理疗法🧘 |

### 标签模板

```
必带标签（每条都加）：
#哲学 #思维方式 #认知提升

系列标签（按内容选）：
思维工具箱 → #批判性思维 #逻辑思维 #思维模型
哲学家列传 → #哲学家 #人物故事 #思想史
东西对话   → #东方哲学 #西方哲学 #文化比较
AI×哲学   → #AI #人工智能 #科技哲学
人生哲学课 → #自我提升 #人生智慧 #心理学
每日一问   → #哲学问题 #思考 #脑洞
原典精读   → #读书 #经典 #哲学入门

热点标签（按话题选）：
#存在主义 #斯多葛 #佛学 #儒家 #道家
#康德 #尼采 #苏格拉底 #庄子 #王阳明
```

## 五、发布checklist

- [ ] 封面标题是否吸引人（有数字/反差/悬念）
- [ ] 每张卡片文字是否控制在50字内
- [ ] 是否有互动引导（提问/选择/投票）
- [ ] 标签是否包含3个必带+2-3个系列+1-2个话题
- [ ] 配色是否符合系列色调
- [ ] 文末是否有关注引导
