## 笔记③（反差干货·易爆）

**标题**：
> 机器人为什么不能用"普通回归"学动作？🤔

**封面文案**：
```
一个反直觉的事实

机器人学动作
直接用MSE回归 = 学废

为什么？
```

**卡片2**：
```
先看个例子

机器人要绕过一个障碍物
可以从左绕，也可以从右绕
两个动作都对✅

但如果用MSE回归...
```

**卡片3**：
```
MSE会取"平均"

左绕 + 右绕
取平均 = 直直撞上去💥

因为MSE的最优解是
所有正确答案的"期望"
两个对的平均，是个错的
```

**卡片4**：
```
这叫"多模态动作分布"问题

同一个画面下
有多个都对但互斥的动作
回归只会给你一个平庸的平均值
```

**卡片5**：
```
正确解法

用"生成模型"建模动作分布👇
· Diffusion Policy（扩散）
· flow matching（π0用的）
· CVAE（ACT用的）

它们能采样出"左绕或右绕"
而不是中间撞墙
```

**卡片6（互动）**：
```
这就是为什么
现在SOTA策略都用扩散/flow

面试高频追问点⚠️
能讲清这个=加分

完整题库+代码 主页领📌
```

**正文caption**：
```
一个面试高频反直觉考点：为什么机器人策略不能直接用MSE回归？

因为动作分布是"多模态"的——同一场景多个动作都对，MSE取平均会得到一个两边都不对的动作（绕障碍取中间=撞墙）。所以现在Diffusion Policy、π0、ACT都用生成模型建模动作分布。

这题能讲清楚，面试官会觉得你真懂。完整解析+代码看主页～

#具身智能 #DiffusionPolicy #大模型 #算法面试 #机器学习 #人工智能 #AI #深度学习 #机器人 #秋招
```
