# M2 · 多模态大模型基础（VLM） — 逐题精讲

> 目标：讲清"视觉怎么进大模型、怎么对齐"。VLM 是 VLA 的地基，很多 VLA 直接拿预训练 VLM 当 backbone。

---

## Q8 ★ 视觉信息如何输入大模型？四种主流方式对比

核心问题：图像是 2D 像素，LLM 吃的是 1D token 序列，如何转换并接入？

| 方式 | 代表 | 机制 | 优缺点 |
|------|------|------|--------|
| **ViT patch → token** | ViT, LLaVA | 图像切成 16×16 patch，线性投影成 token，直接拼到文本 token 前 | 简单有效；token 多、算力大 |
| **对比预训练编码器** | CLIP ViT | 用 CLIP 视觉编码器出全局/patch 特征，再投影 | 语义对齐好；分辨率受限 |
| **Q-Former（查询压缩）** | BLIP-2 | 一组可学习 query 通过 cross-attention 从图像特征"抽取"固定数量 token | 大幅压缩 token 数；训练复杂 |
| **Cross-attention 注入** | Flamingo | 在 LLM 层间插入 gated cross-attention，图像作为 KV | 不改 LLM 主干；改动侵入式 |

**记忆主线**：LLaVA=最简单的"投影拼接"；BLIP-2=Q-Former压缩；Flamingo=层间cross-attn。面试常让你对比 LLaVA vs BLIP-2。

> LLaVA 路线（visual tokens 直接拼接 + 一个 MLP projector）因为**简单、可扩展**，成了当下 VLM/VLA 的主流。

## Q9 ★ CLIP 的训练目标？对比学习为什么对具身有用？

- **目标**：图文对比学习。一个 batch 内 N 个图文对，构成 N×N 相似度矩阵，**对角线（匹配对）拉近、非对角线推远**（InfoNCE 损失）。
- **产物**：一个把图像和文本映射到**同一语义空间**的编码器——零样本分类、检索都靠它。
- **对具身的价值**：
  1. 提供**语义对齐的视觉特征**，让机器人能把"红色杯子"这种语言指令 grounding 到图像区域。
  2. 海量图文预训练带来**开放词汇泛化**，遇到没见过的物体也有语义先验。
  3. 很多 VLA 的视觉 backbone 就是 CLIP/SigLIP，省去从零学视觉。

## Q10 主流 VLM 对齐方式速记

| 模型 | 对齐方式 | 一句话 |
|------|----------|--------|
| **LLaVA** | MLP projector 把 CLIP 特征投到 LLM 词空间，visual token 直接拼接 | 简单粗暴，指令微调 |
| **BLIP-2** | Q-Former 两阶段（表示学习 + 生成学习）桥接冻结的视觉编码器和 LLM | 参数高效 |
| **Flamingo** | Perceiver Resampler + gated cross-attention 插入 LLM | 少样本上下文学习强 |
| **Qwen-VL** | ViT + 适配层，支持多分辨率/定位 | 工业级、中文友好 |

## Q11 什么是 visual token？token 太多怎么办？

- **visual token**：图像经编码器/切patch后得到的、能喂进 transformer 的特征向量序列。一张高分图可能产生上千 token。
- **问题**：transformer 自注意力是 **O(n²)**，token 多→显存爆、推理慢；对实时具身尤其致命。
- **压缩手段**：
  - Q-Former / Perceiver Resampler（固定数量 query 抽取）
  - token merging / pruning（合并相似 token）
  - 降分辨率 / 自适应分辨率（AnyRes）
  - 池化（pooling）

> 对具身而言，token 压缩=推理提速=控制频率提升，是工程刚需。

## Q12 ☆ 为什么 VLA 常直接复用预训练 VLM？

复用 VLM backbone 带来三类**先验**：
1. **语义先验**：理解"把抽屉里的苹果拿出来"的指令语义、物体类别、空间关系。
2. **视觉常识**：识别物体、材质、遮挡，开放词汇泛化。
3. **世界知识**：知道"刀很锋利""杯子装水"，利于安全和合理操作。

这让 VLA 不必从零学感知和语言，只需学"语义→动作"的映射——**数据效率大幅提升**，也是 RT-2/OpenVLA 的核心思路。

## Q13 模态鸿沟（modality gap）

- **定义**：CLIP 等对比学习模型中，图像 embedding 和文本 embedding 各自聚成两簇，在共享空间里**存在系统性间隔**，并非完全混合。
- **成因**：对比损失只要求"匹配对相对更近"，不要求两模态分布重合；加上初始化和温度系数的影响。
- **影响**：跨模态检索/生成时可能有偏差；对需要精细 grounding 的具身任务，需注意特征是否真对齐。

## Q14 ◆ 视频理解相比图像，对具身的价值与难点

- **价值**：
  - 提供**时序/动态**信息（运动、因果、物体如何被操作）。
  - 人类操作视频是**海量、低成本**的具身先验来源（学"怎么做"）。
  - 利于学习**世界模型**（预测未来帧）。
- **难点**：
  - token 数随帧数暴涨，算力/显存压力大。
  - 缺动作标签（视频里没有机器人关节角），存在 embodiment gap，要做动作推断或表征学习。
  - 视角、人手 vs 机械手的形态差异。

> 前沿思路：从人类视频学**可迁移表征/affordance/奖励**，再用少量机器人数据对齐动作。
