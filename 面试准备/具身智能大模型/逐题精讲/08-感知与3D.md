## Q48 ★ 为何常需 3D 表示？各种 3D 表示适用场景

- **为何要 3D**：操作是物理空间里的事——抓取、避障、放置都需要**精确的几何与深度**。纯 2D 有尺度/遮挡歧义，难以精确定位末端到物体的相对位姿。
- **常见 3D 表示**：

| 表示 | 特点 | 适用 |
|------|------|------|
| **深度图(depth)** | RGB-D 直接给，2.5D | 近距离操作、避障 |
| **点云(point cloud)** | 无序点集，几何精确 | 抓取位姿估计、配准 |
| **体素(voxel)** | 规则网格，可做3D卷积 | 占用预测、碰撞检测（稀疏voxel省内存）|
| **网格(mesh)** | 表面拓扑 | 仿真资产、碰撞 |
| **隐式场(NeRF/SDF)** | 连续函数表示 | 高保真重建 |
| **3D Gaussian Splatting** | 显式高斯点，渲染快 | 实时重建、仿真资产、表征 |

## Q49 6-DoF 抓取位姿估计常见做法

- **6-DoF 抓取**：预测夹爪在 3D 空间的位置(3)+姿态(3)，使其能稳定抓住物体。
- **常见方法**：
  - **采样-评估**：在点云上采样大量候选抓取，用网络打分排序（如 **GraspNet / 6-DOF GraspNet / Contact-GraspNet**）。
  - **直接回归**：网络直接从点云/RGB-D 预测抓取位姿。
  - **end-to-end**：把抓取嵌入策略，直接输出动作（VLA 路线）。
- 评价：抓取成功率、覆盖率、对杂乱场景/未知物体的泛化。

## Q50 ☆ NeRF / 3DGS 在机器人里的用途

- **NeRF（神经辐射场）**：用 MLP 表示场景，新视角合成、高保真重建。机器人用途：场景重建、生成仿真资产、做表征。缺点：训练/渲染慢。
- **3D Gaussian Splatting**：用一堆显式 3D 高斯表示场景，**渲染极快（实时）**、质量高。机器人用途：
  - 实时场景重建与数字孪生（real2sim）。
  - 生成逼真仿真环境缩小 visual gap。
  - 作为可微表征支持位姿估计、操作规划。
- 趋势：3DGS 因速度优势在机器人里比 NeRF 更受青睐。

## Q51 如何把空间/几何信息注入 VLA 大模型

- **输入点云/深度**：用点云编码器（PointNet++/3D backbone）出 token 拼接进大模型。
- **3D position embedding**：给视觉 token 加 3D 坐标/相机参数编码，让模型有空间感（如多视角融合）。
- **多视角图像**：用多相机+几何约束隐式提供 3D。
- **物体中心表示**：先检测/分割物体，用其 3D 位姿作为结构化输入。
- **显式中间表示**：先估计 6-DoF 抓取/affordance map，再交给策略。
- 权衡：纯 2D VLA（如 OpenVLA）简单但空间精度弱；注入 3D 提升精度但增加复杂度和传感器依赖。

## Q52 ◆ 仅 RGB 单目能否做好操作？（开放题）

平衡作答：
> "部分可以，但有局限。
> - **支持单目的理由**：大规模数据 + 强视觉先验下，模型能从 2D 学到隐式深度线索（透视、遮挡、阴影、先验尺寸）；RT-2/OpenVLA 等纯 RGB VLA 已能做不少操作；单目硬件便宜、标定简单。
> - **局限**：精细操作（插孔、对齐、堆叠）需要毫米级深度，单目有尺度歧义；遮挡和透明/反光物体困难。
> - **我的判断**：粗操作和语义抓取单目够用；高精度接触丰富任务建议 RGB-D 或多视角，或用 action chunking + 闭环视觉伺服补偿。务实做法是**单目为主 + 深度/触觉在关键阶段补充**。"
